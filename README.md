# MedCore

MedCore is a live view of a hospital for the people who run it, from Inventa Labs.

Leaders see the money, the departments, and staff activity from anywhere. The hospital system itself stays on the hospital's own machines. MedCore shows the picture those machines already keep.

It is for hospital owners and managers who want oversight without moving patient operations off the premises.

Inventa Labs keeps the product source private. This page is the public introduction.
